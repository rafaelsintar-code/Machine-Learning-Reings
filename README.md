# Machine-Learning-Flappy-Bird

 Este proyecto implementa un agente inteligente capaz de aprender a jugar Flappy Bird mediante técnicas de Aprendizaje por Refuerzo Profundo (Deep Reinforcement Learning). El 
sistema combina redes neuronales artificiales con el algoritmo Deep Q-Network (DQN) para que el agente aprenda de forma autónoma a navegar a través de obstáculos sin 
intervención humana ni programación explícita de reglas.
